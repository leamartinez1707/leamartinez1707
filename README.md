## 🔧 UruFix — Multi-Tenant SaaS

> **Production SaaS · Independent Project · Client in production**

UruFix is a multi-tenant SaaS platform for managing technical service businesses.

I originally identified the problem while working at a company that managed its technical service operations using spreadsheets. I proposed building a dedicated system and developed the initial version independently, later evolving it into a multi-tenant SaaS product.

### What I built

- Multi-tenant architecture with tenant-level data isolation
- Authentication and role-based access control (RBAC)
- REST API with Node.js and Express
- MongoDB data layer with tenant isolation
- Recurring subscriptions and payment processing with Mercado Pago
- Secure webhook validation using HMAC
- Analytics and reporting
- Excel/PDF exports
- SMS and email notifications
- Load testing with k6
- Production monitoring with New Relic
- Deployment with Vercel and Railway

**Tech stack**

React · Vite · TypeScript · TanStack Query · Zustand · TailwindCSS · Node.js · Express · MongoDB Atlas · Redis · JWT · Mercado Pago · Resend · k6 · New Relic · Vercel · Railway

🔗 **Live:** https://urufix.com/
